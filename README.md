# Jokenpô
Desafio Jokenpô Básico 🪨📄✂️

Regras do Jogo: Neste desafio de Jokenpô (pedra, papel e tesoura), você enfrentará o computador em uma partida divertida e simples. As regras são as tradicionais:

- Pedra vence Tesoura

- Papel vence Pedra

- Tesoura vence Papel

Escolha sua jogada e descubra se você consegue vencer a máquina!
